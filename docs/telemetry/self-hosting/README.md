# Uptrace setup scripts

Scripts that start and stop a local Uptrace server with Docker, so you can browse
your runs in a web interface. This is optional — telemetry records to a file on
your machine without it.

The same files are at `tools/installer/telemetry-self-host/` (bundled with the installer).

See [SELF_HOSTING.md](../SELF_HOSTING.md) for usage.
